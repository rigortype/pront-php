# ADR-0010: Generation

- Status: Accepted
- Date: 2026-11-07
- Amended: 2026-11-08 (Stage 1 findings: which constructor throwables are discards; the edge ratio
  and iterations are `#[Verify]` options only)
- Refines: ADR-0008 (Pillars 1, 4)

## 1. Ungeneratable types
Types for which no generator can be synthesized (`mixed`, interfaces, classes
with unresolvable constructors) are a pre-run error, never silently skipped.
Users register custom generators to resolve them. Pront provides a
custom-generator registration point but no custom shrinkers.

## 2. Class types
- Class types are generated by recursively resolving public constructor
  parameter types.
- A constructor exception counts as a rejected input (counted toward the
  discard threshold of section 5; its default is in section 4). Here an
  exception is an `Exception`, a `ValueError` or an `AssertionError` (how a
  constructor, a built-in it calls, or `assert()` rejects an argument); any
  other `Error` (`TypeError`, an undefined function, ...) is a failure of the
  code under test, because a discard could hide a bug.
- Recursive types get a size/depth budget recorded in the choice buffer.
- Built-in interfaces such as `DateTimeInterface`, `Countable`, `Stringable`
  have no default mapping; they are pre-run errors resolved by custom
  generators.
- `float` and `enum` are supported; `NaN` and `INF` are edge values.

## 3. Equality
- Scalars and arrays compare structurally including type (`NaN` equals
  `NaN`). Enum cases and closures compare by identity.
- An object of a user-defined class with **no internal class among its
  ancestors** compares by structural deep comparison including type, walking
  the parent chain (parent-private properties included); cycles are detected
  by remembering visited pairs and treated as structurally equal. Interfaces
  are not considered when classifying a class.
- An object whose class **is internal, or has an internal class among its
  ancestors, and whose state reflection cannot see** (`DateTimeImmutable`,
  `ArrayObject`, `SplObjectStorage`, ..., and user subclasses such as `final
  class Bag extends ArrayObject`) is compared through the comparator of its
  nearest such internal class plus its own user-defined properties, because
  property comparison alone would report different values as equal. The
  internal classes that compare structurally like user classes are exactly
  `stdClass` and `Throwable` with its subclasses; every other internal class
  needs a comparator, because declared properties do not imply visible state
  (`PDOStatement`, `ZipArchive`, the DOM classes). A `Throwable` is compared by
  all properties along its class chain except `file`, `line`, `trace` and the
  cached string, which differ with the place of creation (so
  `ErrorException::severity` and `PDOException::errorInfo` count). Stage 2 ships comparators for the `DateTimeInterface`
  implementations, `ArrayObject` and `SplObjectStorage`; the full list is an
  ADR. With no comparator it is an error: pre-run when the declared types
  show it, otherwise a runtime "unverifiable" error (ADR-0013). Users can
  register comparators.
- A value that cannot be compared or snapshotted (an uncloneable object such
  as a `Generator`, an uninitialized typed property, a lazy object whose
  initialization would run user code) can only be seen while running. It makes
  the trial *unverifiable*: reported as a runtime error with exit code 2
  (ADR-0013), counted neither as a pass nor as a discard, and never silently
  treated as equal.

## 4. Edge-value bias
Boundary values from a fixed list (owned by an ADR; initially `0`, `-1`,
`PHP_INT_MAX`, empty string, empty array, supplementary-plane characters, NUL bytes) are
mixed with uniform random values by default, inside the generators.
- Only edge values inside the permitted range are candidates; out-of-range
  ones are dropped, never clamped. The range's own endpoints are edge values.
- "Edge or uniform" is itself the first draw recorded in the choice buffer;
  value 0 means uniform. An edge value takes one draw and is minimal by design
  under the ADR's ordering; the shrinker tries every lower selector value and
  then lowers the position. Reproducibility and shrinking are preserved (ADR-0011).
- Initial defaults (provisional; tuning owned by an ADR): iterations 100, edge
  ratio 10%, discard threshold 10x the iteration count. Iterations and ratio
  are options of `#[Verify]` (`#[Verify(iterations: 200, edgeRatio: 0.25)]`)
  only; the CLI has no option for either, so replay tokens never carry a
  run-wide ratio, and a token without a buffer regenerates its input with the
  ratio the target's `#[Verify]` has at replay time. Stage 1 as merged has
  `iterations` but not yet `edgeRatio` (always 10%); it follows in #37.

## 5. Dependent generation and rejection
- `callable` parameters are a pre-run error ("unsupported until the
  CoArbitrary phase").
- Rejection can still occur (empty `ElementOf` source, empty dynamic range,
  `Regex` with lookaround). Discards are counted; exceeding the threshold is a
  generator-configuration error.
